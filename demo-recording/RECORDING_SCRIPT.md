# FlowSight silent demo recording script

Target length: **55–65 seconds**  
Format: **1920×1080 landscape**  
Demo date: **August 3, 2026**

## Before recording

1. Create a fresh fictional demo account. Do not use personal financial data.
2. Begin onboarding and choose **Import a CSV**.
3. Create a checking account named **Everyday Checking** with a current balance of **$2,740.00**.
4. Import `flowsight-demo-checking.csv` with:
   - Date → `Date`
   - Description → `Description`
   - Amount → `Amount`
   - Spending amounts are negative
5. Confirm the recurring suggestions for:
   - Harbor View Apartments Rent: **−$1,650**, monthly, next August 4
   - Evergreen Auto Insurance: **−$180**, monthly, next August 6
   - Metro Auto Loan Payment: **−$410**, monthly, next August 6
   - Northstar Studio Payroll: **+$2,400**, every two weeks, next August 11
6. Set the safety buffer to **$500**.
7. Finish onboarding before recording the final dashboard sequence.
8. The optional credit-card CSV is only for an additional Accounts/Transactions shot. Do not include it in the main take because it can change the core forecast story.

Expected core result before other forecast events: **$500 projected balance on August 6**, exactly at the safety buffer and five days before the next paycheck. This matters for the scenario: a $650 purchase on August 3 is unsafe, while moving it to August 11 can keep the entire forecast at or above the buffer.

## Capture these clips first

Record each clip separately. Leave one second of stillness at the beginning and end of every clip.

## Editing notes

- Keep each caption to one or two short lines.
- Use the FlowSight rust accent color for amounts, dates and warnings.
- Keep background music around 10–15% volume.
- Use cuts or short dissolves; avoid elaborate transitions.
- Add a subtle zoom only when directing attention to the projected low or scenario result.
- Never show typing mistakes, loading delays, personal browser tabs or notifications.
- If the calculated date differs because you record after August 3, update the recurring dates in the CSV or manually set the next dates during recurring review before capturing the dashboard.
